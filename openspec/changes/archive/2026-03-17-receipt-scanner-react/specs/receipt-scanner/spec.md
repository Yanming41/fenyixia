## receipt-scanner

小票扫描识别的完整 React 实现。

### Requirements

#### 图片上传
1. 支持点击选择文件和拖拽上传
2. 支持 JPEG、PNG、WebP 格式
3. 上传后根据类型决定是否进入裁剪

#### 类型选择
4. 提供"实体小票 🧾"和"数字订单 📱"两种类型
5. 实体小票：上传后进入裁剪流程
6. 数字订单：上传后跳过裁剪直接预览

#### 图片裁剪
7. 全屏 canvas 覆盖层，显示图片 + 四角拖拽手柄
8. 自动检测小票边缘作为初始裁剪区域
9. 支持手动拖拽四角调整裁剪范围
10. 确认裁剪后执行透视变换，输出校正后的 JPEG
11. 可选择跳过裁剪

#### 图片预览与旋转
12. 显示裁剪/上传后的图片预览
13. 支持 90°/180°/270° 旋转

#### 成员选择
14. 显示当前用户 + 所有好友列表
15. 可勾选/取消参与成员（至少保留一人）

#### AI 识别
16. 点击"开始识别"调用 Supabase Edge Function（scan-receipt）
17. 传递 base64 图片 + Claude prompt
18. Prompt 包含：税率规则（13% HST Ontario）、JSON schema、命名规范
19. 显示加载状态，识别失败时显示错误信息并可重试

#### 结果展示与编辑
20. 显示识别出的：图标、商家、日期、商品列表、总金额
21. 每个商品行可点击编辑（名称、数量、单价）
22. 可删除商品行
23. 实时更新总金额和人均金额

#### 成员分配
24. 默认将所有选中成员分配到每个商品
25. 支持拖拽成员头像到商品行进行分配/取消
26. 点击商品行上的成员标签可切换分配状态
27. 实时更新每人应付金额

#### 保存
28. 上传图片到 Supabase Storage（receipt-images bucket）
29. 创建 bill + bill_items 记录
30. 插入 receipt_scans 记录
31. 保存成功后显示 toast 并返回首页

#### 路由集成
32. 注册 `/scan` 路由，受 ProtectedRoute 保护
33. AddBillOverlay 的"📷 拍照/扫描"按钮改为导航到 `/scan`
